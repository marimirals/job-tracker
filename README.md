# Job Tracker

Браузерное расширение и дашборд для тех, кто ищет работу. Сохраняет вакансии в один клик, вытаскивает из них навыки, зарплату и формат работы, а затем показывает, насколько вакансия подходит именно тебе и каких навыков чаще всего не хватает.

## Зачем

Когда откликаешься на десятки вакансий, ссылки теряются, а требования забываются. Job Tracker собирает всё в одном месте и превращает набор вакансий в статистику: что рынок требует чаще всего и чего не хватает тебе.

## Возможности

- **Сохранение в один клик.** Расширение для Chrome и Яндекс Браузера сохраняет вакансию с любого сайта.
- **Разбор вакансий.** Для hh.ru используется официальный API, для остальных сайтов текст страницы разбирает LLM: должность, компания, зарплата, формат, хард- и софт-скиллы.
- **Совпадение с вакансией.** Процент требований, которые ты закрываешь. По нему можно сортировать таблицу и откликаться сначала туда, где совпадение 80%+.
- **Пробелы по вакансии.** В карточке видно, какие навыки у тебя есть, а каких не хватает.
- **Общая статистика пробелов.** Навыки, которых у тебя нет, отсортированные по тому, как часто их требуют.
- **Трекинг откликов.** Статусы от «сохранена» до «оффер» и заметки к каждой вакансии.
- **Тёмная тема**, которая включается по настройке системы.

| Качество кода | ESLint, Prettier |

## Как это работает

1. На странице вакансии нажимаешь «Сохранить вакансию» в расширении.
2. Сервер определяет источник: вакансии hh.ru берёт из официального API, для остальных отправляет текст страницы в LLM и получает структурированный JSON.
3. Навыки нормализуются (`ReactJS`, `React.js` → `React`) и сохраняются в PostgreSQL.
4. Дашборд показывает таблицу вакансий и считает статистику по твоим навыкам.

Если основной LLM-провайдер недоступен или исчерпан лимит, запрос автоматически уходит запасному.

## Структура репозитория

```
job-tracker/
├── extension/   # браузерное расширение
├── web/         # дашборд на React
└── server/      # бэкенд на Go
```

## Быстрый старт

Нужны Node.js 20+, а для бэкенда ещё Go и Docker.

### Бэкенд

```bash
cp server/.env.example server/.env   # впиши свои API-ключи
docker compose up
```

## Настройки

| Переменная | Где | Описание |
|---|---|---|
| `VITE_API_URL` | extension, web | Адрес бэкенда |
| `VITE_DASHBOARD_URL` | extension | Адрес дашборда |
| `VITE_USE_MOCKS` | web | `true` — демо-данные без бэкенда |
| `OPENROUTER_API_KEY` | server | Ключ OpenRouter |
| `OPENROUTER_MODEL` | server | Модель OpenRouter |
| `GIGACHAT_AUTH_KEY` | server | Ключ GigaChat (запасной провайдер) |
| `DATABASE_URL` | server | Строка подключения к PostgreSQL |

## API

| Метод | Путь | Описание |
|---|---|---|
| `POST` | `/api/vacancies` | Сохранить вакансию |
| `GET` | `/api/vacancies` | Список вакансий |
| `GET` | `/api/vacancies/{id}` | Вакансия с навыками |
| `PATCH` | `/api/vacancies/{id}` | Изменить статус или заметки |
| `DELETE` | `/api/vacancies/{id}` | Удалить вакансию |
| `GET` | `/api/skills` | Все навыки из вакансий |
| `GET` | `/api/skills/me` | Мои навыки |
| `PUT` | `/api/skills/me` | Обновить мои навыки |
| `GET` | `/api/stats/gaps` | Статистика пробелов |
